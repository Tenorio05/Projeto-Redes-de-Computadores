# Projeto de Fundamentos de Redes de Computadores
O projeto da disciplina de Fundamentos de Redes de Computadores para o semestre 2026.1 consiste na implementação de um sistema de leilão em tempo real, denominado AuctionCIn, com suporte a múltiplos usuários. O foco principal do projeto é a construção de comunicação confiável utilizando o protocolo UDP e a gestão de estado no servidor. O projeto é dividido em três entregas, são elas:

## Primeira Entrega: Transmissão de arquivos com UDP
Para a primeira etapa, o objetivo é desenvolver a funcionalidade de transmissão de arquivos através de uma conexão UDP utilizando a biblioteca socket na linguagem Python. O processo envolve o cliente enviando um arquivo ao servidor, o servidor armazenando o arquivo e, em seguida, o servidor enviando o arquivo de volta ao cliente. Esta etapa requer o particionamento do arquivo em pacotes de tamanho não superior a 1024 bytes (denominado buffer_size). O vídeo fornecido detalha a estrutura de código necessária para estabelecer e manipular essa comunicação UDP.

## Segunda Entrega: Implementação de uma transferência confiável com RDT 3.0
Na segunda etapa, o objetivo é evoluir o código da entrega anterior para simular uma transferência de dados confiável sobre o protocolo UDP, utilizando o modelo de canal de transmissão RDT 3.0 (apresentado no livro do Kurose). O sistema deve continuar realizando o envio, o armazenamento e a devolução de diferentes tipos de arquivos , mas agora com a implementação da confiabilidade diretamente na camada de aplicação. Para testar a eficiência e a resiliência desse canal, é exigida a criação de um gerador de perdas aleatórias de pacotes, que forçará a ocorrência de *timeouts* e o reenvio de dados. Uma ressalva importante para esta etapa é que não será necessário implementar o mecanismo de *checksum* característico do RDT 3.0, visto que essa verificação de integridade já está presente nativamente no protocolo UDP e na camada de enlace. Além disso, para facilitar o acompanhamento e a avaliação, cada passo da execução do programa (como envio, perda ou recebimento de pacotes) deve ser obrigatoriamente exibido na linha de comando.
